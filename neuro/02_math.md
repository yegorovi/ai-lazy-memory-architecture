# Математика: вектора, матрицы, активации

Этот файл - набор инструментов, которые используются везде дальше. Их четыре: вектор, матрица, умножение матрицы на вектор и функция активации. Если с математикой не дружил - читай по абзацам, тут всё объяснено через понятные вещи, а не через определения из учебника

## Вектор: список чисел как одно значение

Вектор - это просто упорядоченный список чисел: три числа, тысяча чисел, сто двадцать восемь тысяч. Ничего мистического. Числа записаны в определённом порядке, и порядок важен: вектор (3, 1, 4) - не то же, что (4, 3, 1)

Зачем они нужны: когда у объекта много признаков, удобно складывать их в список и работать со списком целиком. Температура, влажность, давление - вектор из трёх чисел. Слово из словаря модели - вектор из сотен чисел, где каждое число отвечает за какую-то сторону смысла (подробно - в файле про токенизацию)

Векторы можно складывать (поэлементно) и умножать на число (умножается каждое число). Обе операции используются потом постоянно, а интуиция простая: сложение векторов - объединение двух наборов признаков, умножение на число - "усиление или ослабление" признаков

## Матрица: таблица чисел, которая умеет менять вектор

Матрица - прямоугольная таблица чисел. Строк и столбцов сколько угодно. Если вектор - список, то матрица - таблица со списком списков

Главное свойство матрицы: она умеет превращать один вектор в другой. Умножил вектор на матрицу - получил новый вектор другой длины, с изменёнными числами. Это и есть основная операция всей нейросети: матрица - это "навык", а вектор - "материал"; навык применён к материалу, получился результат

Формально: каждый элемент результата = сумма произведений. Берётся строка матрицы, умножается поэлементно на вектор, сумма четырёх-пяти слагаемых записывается в ячейку результата. Для чайника хватит интуиции: "матрица пересобирает вектор по своим правилам"

## Умножение матрицы на вектор: пример

Вектор (2, 3). Матрица:

```
1 0
0 2
```

Умножение: первый элемент результата = 1x2 + 0x3 = 2. Второй = 0x2 + 2x3 = 6. Результат - (2, 6): первое число осталось как было, второе удвоилось. Матрица "решила": первый признак не трогать, второй усиливать. Всё - вот и нейросеть в миниатюре: матрица с подобранными числами = обученный нейрон

В больших моделях такие умножения идут пачками: не по одному вектору, а целыми блоками, потому что GPU (видеокарта) идеально заточен под умножение таблиц. Всё "интеллектуальное" в чат-боте в конечном счёте - гигантские матричные умножения, поставленные на поток

## Функция активации: зачем нужна нелинейность

Если слои просто умножают и складывают, сколько слоев ни ставь - математически это эквивалентно одному слою. Умножение на число потом на число - всё равно умножение, выигрыша нет. Чтобы сеть стала способной на сложное, между слоями вставляют нелинейность: функцию, которая кривит результат

Самые известные активации:

Сигмоида выжимает любое число в диапазон от 0 до 1: очень большие входы превращаются почти в единицу, очень маленькие - почти в ноль. Аналогия: тумблер с плавным ходом, который говорит "почти да" или "почти нет"

ReLU самая простая: всё отрицательное обнуляет, положительное пропускает как есть. "Если сигнал слабый - его нет, если сильный - работает". Десятилетия лучшей активации именно из-за дешевизны: обнуление вместо сложных вычислений

GELU как сигмоида, но с гладким провалом около нуля. Ею активируют трансформеры (наш случай)

Смысл один во всех: без активации сто слоёв = один слой, с активацией - сто слоёв умеют описывать любую кривизну

## Softmax: как из чисел делают вероятности

Последний инструмент, и он объяснится в два абзаца. Модель на выходе выдаёт пачку сырых чисел - по одному на каждый возможный следующий токен. Сырые числа называются логиты, они любые: от минус ста до плюс ста, и по ним непонятно, что модель "хочет"

Softmax берёт эту пачку и превращает в пачку вероятностей: все числа становятся от 0 до 1, в сумме дают ровно 1. Механика: каждый логит возводится в экспоненту (чтобы стало положительным), потом всё делится на сумму. Главное свойство - порядок сохраняется: где логит был больше, вероятность будет больше, а разница между большими числами раздувается

Пример: логиты (2, 1, 0.1) превращаются примерно в вероятности (0.66, 0.24, 0.09): модель почти уверена в первом варианте, второй - вероятен, третий - почти исключён. Именно эти вероятности потом выбираются при генерации (как именно - в файле про инференс)
