# default-models - курс по устройству моделей по умолчанию

Эта ветка - отдельная витрина: полный курс про то, как устроены нейросети под капотом, от простого нейрона до защиты от взлома промпта. Всё лежит в папке `neuro/`, читать с нуля лучше сверху вниз, каждый файл стоит на предыдущем

## Индекс курса (папка neuro/)

`neuro/README.md` - карта курса и порядок чтения

`01_neuron.md` - нейрон, веса, слои, почему из тупого кирпича получается умное

`02_math.md` - вектора, матрицы, активации, softmax - инструменты без которых трансформер не понять

`03_tokenization.md` - как текст становится числами: токены, словарь, эмбеддинги

`04_transformer.md` - главный файл: механизм внимания, многоголовость, позиции, сборка модели

`05_training.md` - обучение: функция ошибки, градиентный спуск, предобучение, дообучение, RLHF

`06_inference.md` - генерация: выбор токена, temperature и top-p, KV-кэш, prefill и decode

`07_safety.md` - защита: галлюцинации, инъекции в промпт, jailbreak, alignment, red team

`08_code.md` и `08_code.py` - всё то же самое руками на чистом Python, запускается и показывает вывод

## Что с остальным содержимым ветки

Папка `docs/` и этот файл в основном виде принадлежат главной ветке `main` - архитектуре памяти агента. Здесь они остались как есть, потому что ветка в git это копия всего репозитория целиком, а не набор новых файлов: так устроена система, здесь нет дубляжа, а исходное состояние main. Менять в этой ветке docs не нужно и не стоит - курс в `neuro/`, архитектура памяти в `main`
