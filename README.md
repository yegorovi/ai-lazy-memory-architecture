# old_architecture - курс про архитектуру, с которой ушли

Эта ветка - отдельная витрина: курс про монолитную архитектуру памяти агента - ту, с которой начался наш проект и с которой ушли, но которая до сих пор работает у многих. Всё лежит в папке `old_architecture/`, читать с нуля лучше сверху вниз, каждый файл стоит на предыдущем

## Индекс курса (папка old_architecture/)

`old_architecture/README.md` - карта курса и порядок чтения

`01_monolith.md` - устройство монолита: один инструктаж, одна память, всё в контексте

`02_why_working.md` - почему многие продолжают так работать: ноль настройки, прозрачность, автоматизм среды

`03_limits.md` - где ломается: цена на каждом запросе, дубли, рассинхрон, окно, симптомы и порог

`04_migration.md` - как мы ушли: реальная история 644 КБ в 63 КБ, шесть шагов, ловушки, пороги перехода

`05_landscape.md` - все архитектуры, которые работают сегодня: монолит, ленивая, RAG, summary, гибриды

## Что с остальным содержимым ветки

Папка `docs/` и этот файл в основном виде принадлежат главной ветке `main` - архитектуре памяти агента. Здесь они остались как есть, потому что ветка в git это копия всего репозитория целиком, а не набор новых файлов: так устроена система, здесь нет дубляжа, а исходное состояние main. Менять в этой ветке docs не нужно и не стоит - курс в `old_architecture/`, архитектура памяти в `main`
